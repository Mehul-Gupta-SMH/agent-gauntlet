| File | What it is |
|---|---|
| `banner.svg` | Project banner. Hand-written SVG, presentation attributes only (GitHub strips `<style>` from inline SVG), dark background so it reads on either theme. |
| `demo.gif` | A terminal replay of a **real** gauntlet run. |

The browser demo at [`docs/demo/`](../demo) is generated too — see
*Provenance of the recorded demo* below.

## Provenance of `demo.gif`

Generated by [`tools/make_demo_gif.py`](../../tools/make_demo_gif.py) from
[`experiments/007-m0-gate-passed/console.txt`](../../experiments/007-m0-gate-passed/console.txt),
which is the verbatim output of
[Actions run 35149486157](https://github.com/Mehul-Gupta-SMH/agent-gauntlet/actions/runs/35149486157)
— 324 live runs against `claude-haiku-4-5` and `claude-sonnet-5`.

Nothing in the GIF is drawn by hand. Every number in it traces to a committed
artifact, and the generator reads that artifact rather than a copy of it: if the
demo is wrong, the experiment record is wrong, and both are in git.

That constraint is not decoration. A project whose entire argument is *"do not
trust an output because it looks reassuring"* has no business shipping a
hand-mocked screenshot of a result it never produced.

The only liberties taken are presentational: two lines revealed per frame, a
16-colour palette, and the provenance comment lines from the source file moved
into this caption.

## Provenance of the recorded demo

[`docs/demo/`](../demo) is the arena page replaying two **real** matrices.
Each `replay-*.json` was captured by `gauntlet run --replay`, which attaches
a log to the run that is actually happening and dumps what the harness
emitted — the same stream the live page consumes. There is no code path that
writes one without running the matrix, and none that rebuilds a plausible
stream from a ledger afterwards: a second implementation of the narrative
could drift from the one the UI draws, and on a public page that drift would
be indistinguishable from a mock.

Each file carries its own caption and the exact command that produced it,
both shown on the page. Both recordings are **offline** — scripted policies,
no model called, nothing spent — and say so in those words, because a viewer
who assumes they are watching Sonnet is a viewer the demo has misled.

`index.html`, `arena.css` and `arena.js` are copied from
`src/agent_gauntlet/ui/` by [`tools/build_demo.py`](../../tools/build_demo.py),
with the intake removed (a static page cannot start a run, and a form that
silently does nothing is worse than no form). `arena.js` and `arena.css` are
byte-for-byte identical to the ones the local server serves, and
`tests/test_replay.py` fails if they stop being — a published demo showing an
older product than the repo describes is its own kind of dishonesty.

```bash
python tools/build_demo.py            # rebuild the page from the current UI
python tools/build_demo.py --check    # fail if the committed site drifted
python tools/build_demo.py --record   # re-run both matrices and re-capture
```

Publishing is GitHub Pages from the `main` branch, `/docs` folder — the demo
is then at `/agent-gauntlet/demo/`.

## Regenerating

Pillow is a **tooling** dependency, deliberately not a project one — the
installable package stays at `commonadk`, `pydantic`, `pyyaml`.

```bash
pip install Pillow
python tools/make_demo_gif.py
```

The banner is edited by hand. To preview a change without a browser:

```bash
pip install cairosvg
python -c "import cairosvg; cairosvg.svg2png(url='docs/assets/banner.svg', \
  write_to='/tmp/banner.png', output_width=1200)"
```

Worth doing — the first draft of the banner had three overlapping-text bugs that
were invisible in the source and obvious the moment it was rendered.

## How these were verified on GitHub

Not by looking at the source and reasoning about it:

- **GitHub keeps the markup.** Fetching the rendered repo page shows both
  `<img>` tags surviving sanitisation, rewritten to `/raw/main/...`, alt text
  intact, and the `<details>` block preserved.
- **The served files are the committed files.** `banner.svg` fetched from
  `raw/main` is byte-identical to the one in the repo, served as
  `image/svg+xml`; `demo.gif` matches its committed length as `image/gif`.
- **Rendered in Blink**, the engine GitHub's viewers use, at the real 880px
  README content width, on both the light and dark canvas.
- **Bound-tested against font substitution.** The banner's layout depends on
  text advance widths, and a viewer's browser may pick a different monospace
  or UI font. Substituting a proportional serif for each stack — a far larger
  change than any real platform difference — the left column still clears the
  leaderboard panel by 171px and the tightest bullet gap stays at 78px.

The bullet columns were widened after that measurement: the original gap was
40px, which a 15%-wider system font could have eaten.

## `ui-arena.png`, `ui-intake.png`

Screenshots of `gauntlet ui`, captured from a real offline run — 13
contenders, 104 runs, fixture-derived intake. Not mockups: the board rows,
the injected values in the step log, and the oracle's figures are the run's
own output. The `n/a` cells are real censoring, not placeholders.

## `ui-tools.png`

The wizard's tool step, captured from a real session: two functions uploaded
from one `.py` file, discovered by parsing it, one marked material.

## `ui-credentials.png`

The credentials panel on the models step, with a key set in-session. The
value was typed into a password field and is not visible here, in the page's
HTML, in any response, or on disk — which is the point of the panel.
