I built a leaderboard for AI agents, then spent a week teaching it to say "I don't know."

216 runs, 9 configs, and more than half the board is deliberately blank — 26 of the 45 cells that could hold a number.

One rule did that: a rate nobody measured must never render as a number.

"Propagation: 0%" reads as "faced the corrupted tool, didn't fall for it." If the config never had that tool, the truth is "we have no idea." Same pixels, opposite claims.

So the page computes nothing. Every figure arrives from the scorer, None included, and None renders as n/a.

Six of the nine rows are gated — refused outright, with the reason in the row. And the config that came top was picked on one set of seeds and placed 2nd of 3 on fresh ones, so the page says "the winner did not hold up" instead of crowning it.

There's also a dragon.

The fault injector had no body: faults just appeared on agents with nothing on screen to say where they came from. Now it sleeps through clean runs, wakes when a run is armed, and breathes at whichever agent is being lied to. The colour is the kind of lie.

It only moves on a real faulted event. A test asserts the file contains no setInterval and no Math.random — an animation firing on its own would be the page inventing a fault.

My first dragon was hand-drawn and bad. Replacing it made me read the strike code, where the page was deciding an instruction had been injected by searching tool output for the literal string "SYSTEM NOTICE" — one of five phrasings I support. Scoring was never affected, but the page was inferring something it should have been told.

The demo is a real recorded run, and it says on the page that it's offline and that no model was called.
